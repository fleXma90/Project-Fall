# Bildreferenzen — nur visuelle Richtung

Die vier generierten Konzeptbilder geben Atmosphäre, Silhouette, Plattformwirkung, mobile HUD-Anordnung und grobe VFX-Richtung vor. Sie sind keine echten Godot-Screenshots und keine fertigen Assets.

## Veralteter Titel

Der eingebrannte Name **Forgefall** ist verworfen. Nicht in Projektsettings, UI, Code, Logos oder Storemetadaten übernehmen. Interner Codename: `Project Fall`.

## Dateien

| Datei | Verwenden für | Nicht wörtlich übernehmen |
|---|---|---|
| `01_concept_board.png` | chunky Golem, Schmiede, Waffenidentität, starke Silhouetten | Titel/Branding, Umfang, „Jump gaps“, Währungen |
| `02_mobile_gameplay.png` | Landscape, Joystick links, Attack/Dodge rechts, offene Kanten | Minimap, Coins/Gems, Zusatzleisten |
| `03_desktop_gameplay.png` | 2.5D-Kamerawirkung, Knockback, PC-Präsentation | Q/E/R-Fähigkeiten, Minimap, Währungen |
| `04_upgrade_selection.png` | spätere drei große Run-Auswahlen | konkrete Werte, Back-to-map, Hubpflicht |

## Verbindliche Korrekturen

- kein Jump,
- keine Zielhilfe,
- kein rechter Stick erforderlich,
- normale Plattformen ohne Randwände/unsichtbare Barrieren,
- Attack + Dodge sind die einzigen M1-Kampfaktionen,
- Desktop Maus-Facing; Touch/Controller letzte Stickrichtung,
- technisch **3D**, aber feste 2.5D/isometrische Präsentation,
- M1 baut die Bilder **nicht** detailliert nach: nur Primitive/Dummy-Assets.

Die Referenzen sind per `.gdignore` aus dem normalen Godot-Import ausgeschlossen und dürfen nicht zur Runtime geladen werden.
