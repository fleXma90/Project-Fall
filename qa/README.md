# QA-Ausgaben

Hier können später tatsächliche Logs, Screenshots und kurze gerenderte Aufnahmen pro Auftrag liegen. Das Starterpaket enthält keine solchen Runtime-Nachweise. Generierte Dateien unter `qa/output/` werden nicht automatisch versioniert.

Meilensteinberichte bleiben unter `docs/reports/`. Nur echte Ergebnisse referenzieren; ein Konzeptbild ist kein Screenshot des Spiels. Keine Zugangsdaten, Geräte-Seriennummern oder privaten SDK-Pfade in geteilten Logs belassen.
